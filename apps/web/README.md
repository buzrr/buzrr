# web

The Next.js frontend for **Buzrr** — open-source QuizUp and Kahoot in one app:
ranked 1v1 quiz battles (QuizUp) and live hosted multiplayer quiz rooms
(Kahoot). Also hosts the [Better Auth](https://better-auth.com) endpoints.

See the [root README](../../README.md) for setup — from the repo root:

```sh
yarn setup   # one-command local bootstrap
yarn dev:web # this app only → http://localhost:3000
```
